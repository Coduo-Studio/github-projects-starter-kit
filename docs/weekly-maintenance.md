# Weekly maintenance

Review the project with the people doing the work. Update issues where decisions
are made so the next person or agent sees the same context.

- **Triage incoming work.** Clarify the problem, remove duplicates, and set priority.
- **Check Ready.** Return issues with unresolved decisions or dependencies to Backlog.
  Split Large tasks into independently reviewable changes.
- **Check active work.** Confirm ownership and record the next step for each blocked item.
  Keep fewer issues active than the team can actually progress.
- **Clear the review queue.** Give each item a reviewer or an explicit next action.
- **Reconcile completion.** Check linked PRs and acceptance criteria. Distinguish delivered
  work from issues closed as duplicates or not planned.
- **Find missing metadata.** Use All items to find issues outside the saved working views.
  Assign a status or remove items added by mistake.
- **Prune deliberately.** Archive completed or declined project items when they stop
  helping planning. Archiving a project item does not delete its underlying issue.

Finish with an ordered Ready queue and a named next action for each blocked or
reviewing item. Add iteration planning only when the team needs it.
