# Contribute

Open an issue describing the confusing step or incorrect behavior, or send a small
pull request with the correction. For GitHub interface or syntax changes, include
a link to GitHub's documentation and explain what you checked.

Keep the kit useful with GitHub alone. Product-specific instructions belong in an
optional guide. Prefer examples and copyable files over adding dependencies.

Before sending a pull request:

- Check relative links and filename references.
- Check issue form YAML against [GitHub's form syntax](https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/syntax-for-issue-forms).
- If you change a form, preview it in a test repository's issue chooser and confirm
  required fields behave as intended. Include what you checked in the PR.
- Keep statuses, priorities, and sizes consistent with the project setup guide.
- Mark fictional examples clearly. Use sanitized evidence from your own project.

The repository contains documentation, prompts, and issue forms; it has no app
build or package installation step. Contributions are licensed under the MIT License.
